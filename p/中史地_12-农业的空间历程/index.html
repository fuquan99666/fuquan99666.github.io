农业起源与文明的发展

  • 农业是文明的起源，世界农业最早驯化地有三处，分别是伊拉克的两河流域，中国的长江、黄河中下游地带，墨西哥南部与南美安第斯山区。
  • 大约九千年前后，中国南北方各自形成独立的农业区，北方属于以谷子、黍子为主的旱作农业区，南方则形成以水稻为主的水田农业区。

磁山文化遗址，距今大约9000年，位于河北磁县，是最早的一批文化遗址，遗址中发现了几百个粮食窖穴，每一个窖穴里都有万斤重的粮食，主要是谷子和黍子，表明当时北方已经开始了以旱作农业为主的生产方式。要知道考古发掘时，能发现十几粒粮食就是巨大的收获了，能发现万斤重的粮食就更是不可思议了。

河姆渡文化遗址，距今大约7000年，位于浙江余姚，是中国最早的稻作农业遗址之一。但是在河姆渡遗址刚发掘的年代，西方学者普遍认为水稻最先在东南亚地区驯化。后来，随着长江中游大量更早的稻作农业遗址的发现，考古界逐渐认可了水稻在中国首先驯化。但是，由于河姆渡遗址的年代相比长江中游的稻作农业遗址较晚，所以大多数人认为水稻首先在长江中游驯化。对此，北大一位教授经过研究，发现虽然河姆渡遗址的年代较晚，但是它的水稻品种更好，各种生产工具也更加先进，说明河姆渡遗址是一个发展晚期的稻作农业遗址，一定还有更早的稻作农业遗址等待发现。果不其然，随后在浙江开展的考古发掘中，发现了最早距今11000年的稻作农业遗址。由此，学界认为水稻的驯化最早在中国的长江中下游以及钱塘江下游地区完成。

综上，在人类文明第一次革命-农业革命中，中国首先完成了对水稻、粟子、黍子等主要粮食作物的驯化，（今天地球上60%以上的人都是以水稻为主食的），这是中国古代文明对世界文明的一个重大贡献！

什么是冬小麦？冬小麦是指在秋季播种，经过冬季生长，在次年夏季收获的小麦品种。

为什么冬小麦起源于西亚？因为西亚靠近地中海，地中海气候在7、8月份炎热干燥，而春冬季节温和湿润，适合冬小麦生长。

地中海气候：夏季由于副热带高压的控制，气体沉降，天气炎热干燥；冬季则受西风带的影响，温和湿润。

中国长城以北主要种植春小麦，长城以南主要种植冬小麦。原因是长城以北的冬天气温可能会低于零下22度，直接冻死冬小麦。

玉米和甘薯产量高，适应能力强，在进入中国后迅速传播开来，逐渐取代北方的粟和黍。玉米和甘薯一亩地产量有280斤，而北方的粟和黍一亩地产量只有100斤左右。

马铃薯能够在高海拔地区生长，大大提高了中国一些高海拔、高寒地区的农业生产能力。

纺织作物的嬗变：大麻（纤维）-> 草棉 -> 陆地棉， 宋朝时源自印度的草棉传入中国(灌木类)，经过改良培育，形成了草本棉，在南北推广。19世纪，产于美国的陆地棉引入中国，由于其棉絮长而适合机器加工，在张之洞和张骞的推动下迅速在全国推广开来。 你可能好奇，在棉花传入之前古人是怎么抵御冬天的寒冷呢？穿毛大衣不就好了吗，但是显然并不是所有人都能穿得起毛大衣的，于是古人在两层麻布之间塞入一些动物的皮毛(比如羊)或者是一些草本植物的纤维，来增加衣服的保暖性。

油料作物的嬗变：大麻（油用）-> 芝麻 -> 油菜 -> 花生、大豆。 由于芝麻出油品质好，且适应性强，在中国南北迅速推广。后来，随着油菜传入，由于秋种油菜在南方可以越冬种植，和水稻无缝衔接，所以南方的油料作物逐渐从芝麻转向了油菜(9月种下，来年5月收获)。后来，花生传入中国，一开始花生是作为一种水果，对你没听错，就是一种水果🤣，原因是花生和大豆的大籽粒用传统的人工榨油方法(只能榨取小籽粒和油籽粒)中很难奏效，所以一开始就是吃的。后来随着西方的先进电机榨油方法引入，花生也可以榨油了，由于花生出油量远大于芝麻(在超市里，花生油和大豆油都是一桶一桶卖的，而花生油都是小瓶子卖的，产量致也)，所以北方的油料作物逐渐从芝麻转为花生和大豆。

秋种油菜在南方4月开花，所以我们都说春天要去赏油菜花。而春种油菜主要分布在我国大西北（比如青海地区），大概是7月开花，我们说的大美青海有一个就是7月份盛开的油菜花。

  • 小麦是传入中国最早的外来作物之一，大约在4000年前沿丝绸之路传入中国(如下图所示)，继小麦之后传入的农作物主要有芝麻、占城稻、高粱、油用油菜、玉米、甘薯、马铃薯、棉花等。

上图中很明显有一条从西亚到中国北方的小麦传入路径，需要注意的是在4000年前，丝绸之路并没有正式形成，只是存在一些零散的贸易路径。

占城稻是中国传入越南的水稻经过当地改良培育的一个水稻品种，它的特点是能够适应丘陵地区的低温环境，在传入中国后，只要是能够灌溉的丘陵地区都能种上占城稻！

  • 源于中国本土的农作物主要为北方谷子、南方水稻，经过数千年的农业生产活动，农作物种类不断丰富，仅从粮食作物种类来看，早已不限于谷子、水稻两大类型，外来作物的传入逐渐淡化了本土作物的地位，并通过作物嬗替、取代，建立了新的作物组合形式，从而改变了农业地理的基本格局。

  • 棉分为一年生型草棉与多年生型树棉两种，均为棉属植物，原产地在印度或非洲；中国南方还有一种称为“攀枝花”的乔木，属于木棉属的植物，由于对于它们的生性不熟悉，在古人的记载中常出现混淆。宋以前中原人没有见到草棉、木棉的原物，以为棉就是南方攀枝花树的纤维，对草棉、树棉、木棉不能区别，统称为木棉树。

提一嘴黄道婆对棉花工艺的改进，黄道婆年轻时做了人家的童养媳，因为不能忍受婆婆的压迫，所以逃到了海南岛，由于海南岛离印度比较近，所以早早开始了棉花的种植和加工，黄道婆在海南岛学会了很多先进的棉花加工技术后回到了家乡，改进了棉花加工技术，其中最重要的是棉籽和棉絮的分离技术(棉籽和棉絮十分粘黏，传统分离方法十分麻烦)

曾经中国有三个产棉区——华北平原、长江中下游平原和新疆，现在新疆的棉花产量占全国的90%以上。

  • 玉米为禾本科一年生草本植物，学名Zea mays L，起源于南美洲，7000年前美洲的印第安人就已经开始种植玉米。哥伦布发现新大陆后，把玉米带到了西班牙，随着世界航海业的发展，玉米逐渐传到世界各地。大约16世纪中期，玉米传入中国。
  • 甘薯属一年生或多年生蔓生草本 ，原产南美洲，明代中后期传入中国，由于产量高，环境适应性强，迅速传向各地，成为重要粮食作物。

农业生产技术与地区差异

  • 历史时期中国精耕细作的农业区主要分布在平原地带，丘陵山区则采取粗放生产方式，且以刀耕火种为主。

这个图中绿线右边基本上是中国的农耕区，其中绿色区域为粗放农业区，华北平原以及长江中下游地区则为精耕细作农业区。

黄河流域的两年三熟: 粟播种(第一年3月) -> 收获+冬小麦播种(第一年8，9月) -> 收获+粟播种(第二年5，6月) -> 粟收获(第二年8，9月)

长江流域的一年两熟: 冬小麦收获+水稻播种(4，5月) -> 水稻收获+冬小麦播种(8，9月)

  • 在中国古代经济重心南移进程中，北方南下移民参与所有农业活动的同时，且成为水稻插秧与稻麦复种两项技术的携带者与推广者，这两项技术结束了江南地区火耕水耨的粗放农业，并将土地利用率从50%提升至100%，又从100%提升至200%。中国古代经济重心从北方移向江南是对亚热带水乡农业全面开发过程，其中包括以土地利用与面积扩展为核心的广度开发，以及以精耕细作农业技术提升为主的深度开发两个层面，经唐宋两代，经济重心南移进程中前期以广度开发为主，后期以深度开发为主。
  • 中国历史上农耕区的扩展通过三种方式：
    • 1.绝对面积扩展。
    • 2.土地复种指数提高。
    • 3.高产作物引进。

畜牧业产生与草原游牧方式

《汉书•匈奴传》载：匈奴 “逐水草迁徙，无城郭常居耕田之业，然亦各有分地。” 包括游牧民族在内的非农耕民族经济生活方式有很强的稳定性，在自然环境没发生根本改变，也没有受到异质文化冲击的背景下，他们的经济生活方式一般不会变化，惯有的生活与文化习俗会稳定、不变地持续下去。

  • 决定农牧交错带存在的地理基础仍然在于年降水量的400mm等值线，这条等值线附近亦农亦牧，生产方式具有农牧交融的特点。

所谓的农牧交融不是说既有农民又有牧民，而是说一个人既是农民又是牧民，家里种着几十亩地的同时也放着一批牛羊，即“到处是庄稼，遍地是牛羊”。

  • 中国三大草原：内蒙古草原，天山牧场，青藏高原牧场。

游牧方式 - 逐水草而居

在欧亚大陆中部从中国大兴安岭东西两侧到欧洲多瑙河沿岸，被一条绵延万里的草原覆盖。有一些学者认为游牧民族既然是逐水草而居，那么他们应该没有固定的领地，或者说没有严格的土地意识，然而事实并非如此。在汉书·匈奴传中，东胡向匈奴单于冒顿索要千里马，后者给了；索要妃子，后者给了；最后索要两者之间的一块“无人之地”，后者严厉拒绝了，说“地者国之本也，奈何予人”，说明游牧民族是有很强烈的领土意识的。

  • 划定季节牧场 牧人划定季节牧场，一般需要满足两个原则，其一为保证牧场有良好的再生能力，且植物成分不被破坏；第二为饮水条件以及牧草生长状况可以满足季节要求。根据牧场自然环境不同，可以分为四季营地、三季营地以及两季营地。

四季营地中最重要的是夏季营地和冬季营地，夏季营地一般位于北边的高地，十分凉爽；冬季营地一般在南边向阳的地方，比较温暖，冬天的时候翻开地上积雪能找到干草作为牧草。牧民们每年都在这两个营地之间迁徙，中间可能会有春、秋季营地。在季内，牧民们同样会进行迁移，因为一个地方的水草资源是有限的，大概两三天就会被吃光(牧民会今天往东边放牧，明天往西边放牧…)，所以每过几天牧民就会进行转场，转场的范围一般在几十公里，转了一圈回来之后，之前放牧的地方又长出了新的牧草，可以继续放牧。

草原上不太可能出现很多个营地在一处的情况，因为放牧对牧草的消耗很快，每个牧民都需要百里或者数百里的圈，保证有足够的水草条件来放牧。所以如果你在草原上看到哪个地方有很多蒙古包，那么一定是旅游景点🤣，真正的放牧是孤独的。

  • 规定游牧路线 牧民逐水草而居的游牧生活虽然具有随意性的特点，但游牧路线一般不轻易改变，每年基本都一样，形成这样现象的原因与水源有无、草场优劣以及去年迁移中畜群留下来的粪便都有关。

我们在城市中需要遵循交通路线是因为我们没有翅膀，不可能从高楼上飞过去。但是为什么牧民们每年都要走固定的转场路线呢？因为，在草原上，水源是非常重要的，牧民需要确保转场路线上有足够的水源来满足自己和牧群的饮水需求；同时，由于草原上没有树，牧民想要搜集燃料的话就得利用上一次转场牛羊留下的粪便来烧火。

  • 营盘与放牧 营盘为牲畜过夜休息的地方，牧民一般白天在营盘周围一定范围内放牧，夜晚归宿营盘。由于营盘的功能特征，往往设在牧场的中心地带。按类型可分为临时、固定与辅助营盘。 饮水是放牧中的重要环节，因此牧民确定一天之内的放牧距离基本以饮水地点为半径。

由于不同的牲畜运动能力不同，牧民们会选择不同的放牧半径，比如马的脚力最快，一般在20公里，牛一般在15公里，羊一般在10公里。如此一来，在前面的牛马吃完了高草后，羊就可以吃掉剩下的矮草了。

游牧空间 - 各有分地

  • 牧场划分为不同的区域，成为固定的部族或部落放牧场所，草原民族的季节迁移、转换营地基本限于在划定的区域内进行，越过界线到其它部落牧场内放牧的现象虽然在草原上不是新鲜事，但以一个区域为基本核心构成游牧空间，却是草原上通行的习惯。

事实上，清朝时期的游牧空间划分已经非常细致了，每个部落都有自己固定的牧场，不会存在某个强大的部族凭借武力迫使弱小部落迁徙，进而发展壮大对抗政府，这既维持了草原稳定，也有效削弱了游牧力量的整合能力。
